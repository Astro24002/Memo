# RAG (Retrieval-Augmented Generation)

## 为什么学
RAG技术结合了检索和生成的优势，是构建知识增强型AI应用的核心技术。学习RAG能够解决大模型幻觉问题，提升回答的准确性和可追溯性。

## 学什么
- RAG架构设计模式
- 向量数据库选型与优化
- 文档处理与分块策略
- 检索算法与排序优化
- 混合检索技术

## 核心问题
- 如何提高检索的相关性和准确性？
- 如何处理大规模知识库的实时更新？
- 如何优化向量检索的性能？
- 如何评估RAG系统的效果？

## 推荐路线
1. 理解RAG基本原理和适用场景
2. 学习向量嵌入模型的使用
3. 掌握主流向量数据库(Pinecone、Milvus等)
4. 实践文档处理和索引构建
5. 探索高级RAG变体(GraphRAG、HyDE等)
