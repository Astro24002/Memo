# Vector Database

## 为什么学
向量数据库是AI时代的核心基础设施，支撑着语义搜索、推荐系统、RAG等关键应用。掌握向量数据库技术对于构建智能化应用至关重要。

## 学什么
- 向量相似度算法
- 向量索引结构与优化
- 主流向量数据库对比
- 向量数据建模
- 混合查询能力

## 核心问题
- 如何选择合适的向量索引算法？
- 如何平衡检索精度和性能？
- 如何处理高维向量数据？
- 如何实现向量与传统数据的联合查询？

## 推荐路线
1. 理解向量嵌入的基本原理
2. 学习常见相似度度量方法
3. 掌握HNSW、IVF等索引算法
4. 实践Milvus、Pinecone、Chroma等数据库
5. 探索向量数据库在业务场景的应用
