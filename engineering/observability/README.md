# Observability

## 为什么学
可观测性是现代分布式系统的核心能力。通过监控、日志、追踪三位一体的可观测性体系，能够快速定位问题，保障系统稳定运行。

## 学什么
- Metrics指标监控
- Logging日志管理
- Tracing分布式追踪
- 告警策略与通知
- 可观测性平台搭建

## 核心问题
- 如何构建全面的监控体系？
- 如何实现问题的快速定位和根因分析？
- 如何设置合理的告警阈值避免告警疲劳？
- 如何关联不同维度的可观测性数据？

## 推荐路线
1. 理解可观测性的三大支柱
2. 学习Prometheus监控体系
3. 掌握ELK/Loki日志方案
4. 实践Jaeger/Zipkin分布式追踪
5. 构建统一的可观测性平台
