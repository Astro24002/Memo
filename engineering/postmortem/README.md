# Postmortem

## 为什么学
事后复盘是持续改进的重要环节。通过系统性的故障复盘，能够从问题中学习，避免重复犯错，不断提升系统的可靠性和团队的应急响应能力。

## 学什么
- 无责备复盘文化
- 故障时间线重建
- 根因分析方法
- 改进行动跟踪
- 复盘报告撰写

## 核心问题
- 如何营造安全的复盘氛围？
- 如何找到真正的根本原因而非表面症状？
- 如何确保改进措施有效落地？
- 如何将复盘经验转化为组织知识？

## 推荐路线
1. 理解无责备文化的价值
2. 学习5 Whys等根因分析方法
3. 掌握故障时间线重建技巧
4. 实践SMART原则制定改进行动
5. 建立复盘知识库和分享机制
