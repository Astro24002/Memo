# Platform Engineering

## 为什么学
平台工程是提升研发效能的关键实践。通过构建内部开发者平台(IDP)，能够降低认知负荷，提升开发效率，实现自助式服务。

## 学什么
- 内部开发者平台设计
- 平台API与抽象层
- 自助式服务门户
- 平台成熟度评估
- 开发者体验优化

## 核心问题
- 如何平衡平台标准化和灵活性？
- 如何度量平台工程的ROI？
- 如何推动开发者采用平台能力？
- 如何持续演进平台功能？

## 推荐路线
1. 理解平台工程的核心理念
2. 学习Backstage等平台框架
3. 掌握平台API设计原则
4. 实践Golden Path最佳路径
5. 建立平台反馈和改进机制
