# Talent Mobility

## 为什么学
人才流动研究揭示了人力资源配置和创新传播的规律。理解人才流动模式有助于优化人才引进策略，促进知识转移，提升组织创新能力。

## 学什么
- 人才流动理论与模型
- 社会网络分析方法
- 人才流动数据挖掘
- 区域人才吸引力评估
- 人才政策效果分析

## 核心问题
- 如何预测和引导人才流动趋势？
- 人才流动对技术创新有何影响？
- 如何评估人才政策的 effectiveness？
- 如何构建吸引和留住人才的生态系统？

## 推荐路线
1. 学习劳动力经济学基础理论
2. 掌握社会网络分析工具
3. 实践人才数据收集和清洗
4. 分析人才流动与区域发展关系
5. 探索大数据在人才研究中的应用
