# Complex Network

## 为什么学
复杂网络理论是研究现实世界复杂系统结构和演化的重要工具。通过学习复杂网络，能够理解社交网络、知识图谱、生物网络等系统的内在规律。

## 学什么
- 图论基础与网络表示
- 小世界网络与无标度网络
- 网络中心性指标
- 社区发现算法
- 网络演化模型

## 核心问题
- 如何建模和分析复杂网络结构？
- 如何识别网络中的关键节点？
- 如何发现网络的社区结构？
- 如何理解网络的鲁棒性和脆弱性？

## 推荐路线
1. 学习图论基本概念和术语
2. 掌握常见复杂网络模型(ER、BA等)
3. 学习NetworkX等图分析工具
4. 实践 centrality 计算和社区发现
5. 探索复杂网络在实际场景的应用
