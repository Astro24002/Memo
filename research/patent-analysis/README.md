# Patent Analysis

## 为什么学
专利分析是洞察技术发展趋势和竞争格局的重要手段。通过系统性的专利分析，能够发现技术创新热点，评估技术价值，指导研发决策。

## 学什么
- 专利文献结构与检索
- 专利指标体系构建
- 专利引文分析
- 技术生命周期分析
- 专利地图与可视化

## 核心问题
- 如何从海量专利中提取有价值的信息？
- 如何识别核心技术和技术演进路径？
- 如何评估专利的质量和价值？
- 如何利用专利分析指导技术创新？

## 推荐路线
1. 了解专利制度和分类体系
2. 掌握专利数据库使用技巧
3. 学习专利计量分析方法
4. 实践专利可视化工具
5. 探索AI在专利分析中的应用
