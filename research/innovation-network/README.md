# Innovation Network

## 为什么学
创新网络研究揭示了知识流动和技术创新的传播机制。理解创新网络有助于把握技术发展趋势，优化研发合作，促进创新生态建设。

## 学什么
- 创新扩散理论
- 产学研合作网络
- 知识流动与转移
- 技术创新生态系统
- 专利引用网络分析

## 核心问题
- 如何识别创新网络中的关键参与者？
- 知识如何在创新网络中传播和演化？
- 如何评估创新网络的效率和活力？
- 如何构建有利于创新的协作网络？

## 推荐路线
1. 学习创新理论和网络科学基础
2. 掌握专利数据分析方法
3. 实践合作网络构建和可视化
4. 分析创新集群和知识溢出效应
5. 探索创新政策对网络结构的影响
