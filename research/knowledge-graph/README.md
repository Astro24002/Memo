# Knowledge Graph

## 为什么学
知识图谱是结构化表示和管理知识的核心技术。掌握知识图谱能够构建智能问答、语义搜索、推荐系统等AI应用，实现知识的深度融合和推理。

## 学什么
- 知识表示与本体建模
- 知识抽取技术(实体识别、关系抽取)
- 知识融合与消歧
- 图数据库与查询语言
- 知识推理与应用

## 核心问题
- 如何从非结构化数据中抽取知识？
- 如何解决知识冲突和数据质量问题？
- 如何高效存储和查询大规模知识图谱？
- 如何实现基于知识的推理和预测？

## 推荐路线
1. 学习RDF、OWL等知识表示标准
2. 掌握Neo4j、JanusGraph等图数据库
3. 实践NER和关系抽取算法
4. 探索知识图谱与大模型结合
5. 构建垂直领域知识图谱应用
