# Methodology

## 为什么学
研究方法论是开展科学研究和技术探索的基础。掌握系统性的研究方法能够提升问题分析能力，确保研究的科学性和可重复性。

## 学什么
- 科学研究范式
- 定性与定量研究方法
- 实验设计与数据分析
- 文献综述与批判性思维
- 学术写作与表达

## 核心问题
- 如何提出有价值的研究问题？
- 如何选择合适的研究方法？
- 如何保证研究的效度和信度？
- 如何系统地分析和解释研究结果？

## 推荐路线
1. 学习科学研究的基本原则
2. 掌握文献检索和管理工具
3. 实践研究设计和数据收集方法
4. 学习统计分析软件(SPSS、R等)
5. 持续练习学术写作和演讲技巧
