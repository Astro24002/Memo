# Algorithms

## 为什么学
算法是计算机科学的基石，是解决复杂问题的核心工具。掌握算法能够提升编程能力，优化系统性能，在面试和实际工作中都具有重要价值。

## 学什么
- 基础数据结构与算法
- 排序和搜索算法
- 动态规划与贪心算法
- 图算法
- 字符串匹配算法

## 核心问题
- 如何选择合适的算法解决实际问题？
- 如何分析算法的时间和空间复杂度？
- 如何在性能和可读性之间取得平衡？
- 如何将算法思维应用到工程设计中？

## 推荐路线
1. 掌握基本数据结构(数组、链表、树、图等)
2. 学习经典算法思想和设计模式
3. 实践LeetCode等在线编程平台
4. 理解算法在实际系统中的应用
5. 持续练习和总结算法技巧
