# Storage

## 为什么学
存储系统是数据持久化的基础。理解不同存储介质的特性和存储系统的设计原理，能够合理选择存储方案，优化数据访问性能，保障数据安全。

## 学什么
- 存储介质与硬件(RAID、SSD等)
- 文件系统原理
- 块存储、文件存储、对象存储
- 分布式存储系统
- 存储性能优化

## 核心问题
- 如何选择合适的存储类型和方案？
- 如何保证数据的可靠性和持久性？
- 如何优化存储系统的I/O性能？
- 如何实现存储的弹性扩展？

## 推荐路线
1. 理解存储层次结构和各种存储介质特性
2. 学习文件系统原理(Linux ext4、XFS等)
3. 掌握主流存储协议(NFS、iSCSI、S3等)
4. 实践分布式存储(Ceph、GlusterFS等)
5. 探索云存储和Serverless存储方案
