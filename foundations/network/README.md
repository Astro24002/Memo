# Network

## 为什么学
计算机网络是互联网时代的基础设施。深入理解网络原理和协议，能够优化应用性能，排查网络问题，构建安全可靠的分布式系统。

## 学什么
- OSI七层模型与TCP/IP协议栈
- HTTP/HTTPS协议详解
- TCP连接管理与拥塞控制
- DNS解析与CDN原理
- 网络安全基础

## 核心问题
- 如何优化网络传输性能？
- 如何诊断和解决网络连接问题？
- 如何保障网络通信的安全性？
- 如何设计高可用的网络架构？

## 推荐路线
1. 理解网络分层模型和各层职责
2. 深入学习TCP/IP协议族
3. 掌握HTTP协议和RESTful API设计
4. 实践网络抓包和分析工具(Wireshark、tcpdump)
5. 探索SDN和网络虚拟化技术
