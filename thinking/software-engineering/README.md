# Software Engineering

## 为什么学
软件工程是构建高质量软件系统的系统性方法。掌握软件工程思想和实践，能够提升代码质量，优化开发流程，构建可维护和可扩展的软件系统。

## 学什么
- 软件开发生命周期
- 敏捷开发与DevOps
- 设计模式与架构原则
- 代码质量与重构
- 测试策略与质量保证

## 核心问题
- 如何平衡快速迭代和代码质量？
- 如何选择合适的设计模式和架构风格？
- 如何建立有效的代码审查机制？
- 如何度量和管理软件复杂度？

## 推荐路线
1. 学习软件开发基本原则(SOLID、DRY等)
2. 掌握常见设计模式和应用场景
3. 实践TDD和BDD测试方法
4. 探索微服务和领域驱动设计
5. 持续反思和改进工程实践
