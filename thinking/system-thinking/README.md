# System Thinking

## 为什么学
系统思维是理解和解决复杂问题的关键能力。通过系统思维的视角，能够洞察事物之间的关联和反馈，避免局部优化，做出更全面的决策。

## 学什么
- 系统思维基本概念
- 因果回路图与系统基模
- 反馈循环与延迟效应
- 杠杆点识别
- 系统动力学建模

## 核心问题
- 如何识别系统中的关键要素和连接关系？
- 如何理解非线性因果关系？
- 如何找到解决问题的最佳杠杆点？
- 如何避免系统性思维和决策陷阱？

## 推荐路线
1. 学习系统思维基本原理
2. 练习绘制因果回路图
3. 分析经典系统基模案例
4. 将系统思维应用到实际问题
5. 培养整体性和动态性思维习惯
